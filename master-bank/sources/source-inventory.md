Uploaded specialty-focused MCQ collections include Neonatology, Cardiology, Nephrology, Rheumatology, Endocrinology, Gastroenterology, Hematology, Neurology, Infectious Diseases, Emergency Medicine, PICU and mixed general-pediatrics review material.

## Import policy

- Duplicate PDF copies do not create duplicate source records.
- Duplicate questions across different years are linked to one canonical question.
- Repeated-year appearance is retained as metadata because it is useful for identifying high-yield/repeated board concepts.
- Image-dependent questions must retain image provenance/status.
- Source answer, verified answer, and verification evidence are separate fields.
